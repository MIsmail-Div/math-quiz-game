# 🧮 Math Quiz Game (C++)

A console-based Math Quiz Game built using C++.

This project was created to practice problem-solving, structured programming, clean code principles, and working with functions, enums, structs, and vectors.

---

## ✨ Features

* Generate random math questions.
* Multiple difficulty levels:

  * Easy
  * Medium
  * Hard
  * Mix
* Multiple operation types:

  * Addition
  * Subtraction
  * Multiplication
  * Division
  * Mix
* Tracks correct and incorrect answers.
* Displays the final quiz result.
* Colored feedback for correct and wrong answers.
* Option to play multiple rounds.

---

## 📚 Concepts Used

* Functions
* Enumerations (enum class)
* Structures (struct)
* Vectors
* Random Number Generation (Mersenne Twister)
* Input Validation
* Clean Code Principles
* Modular Programming

---

## 🎮 Game Flow

1. Choose the number of questions.
2. Select the difficulty level.
3. Select the operation type.
4. Answer the generated questions.
5. Receive instant feedback after each answer.
6. View the final score and result.
7. Play again if desired.
